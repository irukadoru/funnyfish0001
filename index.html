■ 如何讓朋友在手機/電腦上一起即時聊天？（3 分鐘免費上架教學）

1. 前往 Firebase Console 免費建立專案 → 新增「網頁應用程式 (Web)」並啟用「Firestore Database（測試模式）」與「匿名登入 (Anonymous Auth)」。

2. 將取得的 firebaseConfig 物件貼入下方輸入框並儲存。

3. 點擊下方「下載已綁定雲端的海豚堂 HTML」，把下載的 index.html 拖曳上傳到 Netlify Drop 或 GitHub Pages，產生專屬網址後分享給朋友即可多人即時同步！
